- State machine (ASCII):
  NEW -> (outbox enqueued) -> IN_PROGRESS -> (success) -> COMPLETED

- Idempotency: dedupe by request_id (client-supplied), persisted into DB, prevents duplicate side-effects.
- Outbox & Saga: write event and state in same transaction; worker consumes outbox and on external success marks COMPLETED; on post-success DB failure run compensation (e.g., cancel).
